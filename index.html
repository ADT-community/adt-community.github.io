Getting paid

Two ways to earn.

The price is agreed before work starts, so there are no surprises and nothing to argue about later.

Bounties

A fixed price for a task

Issues carry a label like bounty:$50. Whoever's pull request gets merged gets paid.

  • Claim the issue first so no one duplicates work
  • Paid after merge
  • Good for features, fixes, designs and docs
Goals

A reward when the project hits a target

Bigger milestones like launch the MVP, first 1,000 users or first paying customer carry a reward for the team.

  • Team and shares agreed at the start
  • Paid when the goal is reached
  • Good for hardware builds and long efforts

Payouts go by mobile money or bank transfer. Payment details are only ever shared privately, never in public issues or discussions.

Every project is a business

Built to make money.

Code is open. Revenue comes from hosting, premium features, fees, licensing and partnerships. Projects with no path to profit get paused, so effort goes where it pays.

Community rules

Keep it respectful.

Do

  • Be patient, especially with newcomers
  • Critique work, not people
  • Credit others honestly

Don't

  • Harass or discriminate, including by country, tribe, religion, gender or language
  • Claim others' work or game bounties
  • Share anyone's private or payment details

Report problems with GitHub's "Report content" option or by messaging a maintainer. Moderators can remove content, cancel bounties earned in bad faith, or ban people.
