# ADT Community

Open source projects solving African problems, built by developers across the continent, who get paid through bounties and goals.

- **Website:** https://adt-community.github.io
- **Propose a project:** https://adt-community.github.io/propose.html
- **Discussions:** https://github.com/ADT-community/adt-community.github.io/discussions

This repo holds the website, project proposals (as issues) and community docs.

## Partner sales kit

For signing the first company that pays to post tasks on ADT Work (issue #12):

- [One-pager PDF](docs/sales/one-pager.pdf) — the pitch to send to a prospect
- [Pricing](docs/sales/pricing.md) — 15% platform fee ($3 on a $20 task) and the two-task pilot
- [30 target companies](docs/sales/target-companies.md) — public contact routes and a first task for each

The one-pager is generated by `docs/sales/generate_one_pager.py` (Python standard library only).
Check the kit with `python docs/sales/test_sales_kit.py` from the repo root.
