# ADT Weekly Update #1 — 19 November 2026

> Launch week: ADT Work task board is live, community Discord opened with automated bounty feed, and five projects seeded.

---

## Shipped

- **ADT Work Task Board ([`work.html`](https://adt-community.github.io/work.html))**:
  - Launched cross-repo task board aggregating open bounties and next-wave tasks from all ADT repositories.
  - Implemented dynamic client-side filtering by skill type (Design, Code, Research, Operations), pay tier ($20, Next wave), beginner level, and open status.
  - Added session caching for GitHub REST API calls to avoid rate-limiting.
- **Project Proposals Portal ([`propose.html`](https://adt-community.github.io/propose.html))**:
  - Live community proposal submission and voting system.
  - Transparent criteria established: clear path to profitability, maintainer commitment, and at least 3 contributors.
- **ADT Community Discord Server ([`docs/discord.md`](../discord.md))**:
  - Server structure initialized with dedicated channels: `#welcome`, `#announcements`, `#how-we-pay`, `#rules`, `#ideas`, `#help`, and project channels (`#trans_sport`, `#locallity_ai`, `#content_feed`, `#adt_agent`, `#trader`, `#community-site`).
  - Community rules and enforcement standards from [`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md) integrated into server rules and onboarding.
  - Privacy policy explicitly preventing public sharing of payment or mobile money details.
- **Automated Discord Bounty Bot ([`bot/bounty_bot.py`](../../bot/bounty_bot.py))**:
  - Python-based feed bot streaming new issues labeled `bounty` or `next-wave` to the `#bounties` Discord channel.
  - Generates rich Discord embeds with project name, bounty price, time estimate, skill level, and claim guidelines.
  - Accompanied by full test suite (`tests/test_bounty_bot.py`) and GitHub Actions workflow (`.github/workflows/bounty-feed.yml`).
- **Flagship Project Repositories Initialized**:
  - Minibus app (`ADT-community/trans_sport`)
  - Local-language AI (`ADT-community/locallity_ai`)
  - Creator social app (`ADT-community/content_feed`)
  - ADT agent (`ADT-community/ADT_agent`)
  - Quant trading lab (`ADT-community/trader`)

- **Current payout run:** Launch period setup.

  - Work merged Monday to Sunday is paid by the following Wednesday.
  - Payout methods: Mobile Money (M-Pesa, MTN MoMo, Airtel Money, Orange Money) and direct bank transfer.
  - First formal payout run starts **Wednesday, 6 January 2027**. All work merged prior to that date will be accumulated and paid out in that first run, followed by weekly payout runs every Wednesday.
