# Weekly updates

A public log of what ADT Community shipped, paid and is about to do next. The habit is simple: every Monday a maintainer writes four short sections — **Shipped**, **Paid**, **New tasks**, **Next** — using [template.md](template.md), posts it in `#announcements` on Discord and commits it here.

See [docs/discord.md](../discord.md) for the server set-up and the channel list. Updates are also mirrored from Discord to this folder so people who do not use Discord can follow progress.
