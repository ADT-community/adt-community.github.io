# ADT Weekly Updates

> **Momentum is visible: people join communities that ship every week.**

The ADT Community maintains an open, consistent weekly update habit. Every week, we document what was shipped across all projects, what was paid to contributors, what new tasks are open, and what is next.

---

## The Four Pillars of Every Update

Every weekly update must follow the format defined in [`template.md`](template.md):

1. **Shipped:** Concrete progress—merged PRs, released features, launched tools, and closed milestones across all ADT repositories.
2. **Paid:** Payout numbers, bounty disbursements, and contributor rewards. Transparency builds trust.
3. **New tasks:** Newly posted bounties, next-wave tasks, and open issues ready for contributors to claim on [ADT Work](https://adt-community.github.io/work.html) and in the Discord `#bounties` channel.
4. **Next:** Top 3–5 focus areas and objectives for the upcoming week.

---

## Publication Schedule & Workflow

- **Cadence:** Weekly, published every **Wednesday** alongside the weekly payout run.
- **Scope:** Covers contributions merged from Monday 00:00 UTC through Sunday 23:59 UTC of the previous week.
- **Workflow:**
  1. **Collect:** Maintainers review merged PRs, closed issues, and new tasks across all repositories:
     - `trans_sport`
     - `locallity_ai`
     - `content_feed`
     - `ADT_agent`
     - `trader`
     - `adt-community.github.io`
  2. **Calculate:** Verify all bounties earned for the payout run.
  3. **Draft:** Create a new markdown file named `YYYY-MM-DD.md` in `docs/updates/` using `template.md`.
  4. **Publish:** Merge the update file into `main`.
  5. **Broadcast:**
     - Post the update text to `#announcements` on the [Discord server](../discord.md).
     - Cross-post to [GitHub Discussions](https://github.com/ADT-community/adt-community.github.io/discussions).
